# Выбор размерной сетки

Шаблоны этой директории предназначены для `wp-content/themes/slds/single_product/`. Перед копированием нужно проверить отсутствие изменений в целевых файлах, сохранить резервные копии и проверить PHP. `cache-invalidation.patch` применяется к `prepare_data.php`: изменение шаблонов должно менять Last-Modified, иначе браузер продолжает получать старую карточку через 304.

При единственной подходящей таблице она видна сразу. При нескольких таблицах показывается подписанный выбор бренда и раздела; одновременно видна только выбранная таблица. Основной бренд не угадывается по порядку терминов. Если в товаре явно сохранён `_slds_size_chart_brand_id`, используется только этот бренд, причём ID обязан входить в назначенные товару бренды. Автоматическое заполнение этого поля данным изменением не выполняется.

Выбор на витрине не подтверждает применимость общей таблицы ко всем моделям Moon Boot или Lemaire.

`slamdunk_size_converter_api.php` устанавливается в `wp-content/themes/slds/inc/`. Конвертер принимает `model_ids[]`; для бренда с метаданными `_slds_size_chart_model_ids` выбирается ровно одна таблица, связанная с переданной моделью и категорией. Метаданные имеют вид `{полный_ключ_таблицы: [числовые_ID_pa_model]}`. Отсутствующая или неоднозначная привязка блокирует преобразование. Диапазоны остаются диапазонами, соседние размеры не подбираются. Бренды без таких метаданных сохраняют обычный выбор по категории. Экспортёр передаёт модели и учитывает их в ключе кэша; основным остаётся source-бренд.

`queue-recovery.patch` применяется через `git apply --unidiff-zero` к `wp-content/themes/slds/inc/catalog/admin/target-import/queue.php` после проверки базовой версии. Проверка наличия работы видит просроченные processing-задания даже при отсутствии pending, чтобы штатный claim_batch мог восстановить очередь. Пауза, разделение очередей и сроки блокировки сохраняются. Проверка: `php scripts/test-wordpress-model-size-and-queue.php <конвертер.php> <queue.php>`.

Переключатель совместим с событием темы `selectCallback` и стандартным `change`. Класс select обязателен для текущей темы. Ширина колонок ограничена конкретной таблицей, чтобы скрытая таблица с другим числом колонок не меняла отображение выбранной.

Проверки: `scripts/test-wordpress-size-chart.php <директория> multiple|primary|empty`, `tests/unit/wordpress-size-chart-choice.test.ts`, PHP lint и реальное переключение adidas/BAPE на товаре 12382.
