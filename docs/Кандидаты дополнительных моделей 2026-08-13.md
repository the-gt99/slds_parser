# Кандидаты дополнительных моделей WordPress

Состояние production на 13 августа 2026 года. Это отчёт для проверки, он сам ничего не меняет.

## Что проверено

- сохранённый импорт WordPress: 184 151 товар;
- свежие индивидуальные снимки WordPress: 421 товар;
- текущая классификация и активные дополнительные назначения;
- учитывались только случаи, где уточнённая модель начинается с полного названия старой модели на том же товаре;
- уже существующие дополнительные назначения исключены.

Всего найдено 131 подтверждённое историей WordPress сочетание. Для 41 сочетания базовая модель уже добавляется. Осталось 90 сочетаний: 37 с числовым окончанием и 53 со словесным. Они подтверждаются 224 товарными наблюдениями.

Важно: совпадение названия является кандидатом, а не доказательством иерархии. Например, `Nike Air Max → Nike Air Max 90` находится обычным поиском по цифрам, но это не означает, что такую связь можно создавать автоматически без принятой бизнес-политики.

## Что делать при применении

Для каждой подтверждённой строки создать каноническое дополнительное назначение внутреннего значения:

1. `product.model` → базовый термин модели;
2. если нужно сохранить и обе посадочные метки, отдельно `product.tag` → `tag_id` базовой модели.

Все 78 уникальных базовых моделей из остатка имеют `tag_id` в справочнике WordPress, поэтому базовые `product_tag` можно добавлять без создания новых терминов.

После применения нужно поставить затронутые товары только на `reclassify_product`, затем заново выполнить preflight. Экспорт в WordPress этим действием не запускается.

## Что не включено в пакет

Отдельный поиск только по названиям находит ещё сотни сочетаний без исторического подтверждения WordPress. В нём встречаются как правильные поколения (`Nike Quest 3–6`), так и слишком широкие связи (`Nike Air Max → Nike Air Max 90`). Такие строки нельзя применять одной эвристикой по цифрам. Их нужно проверять сериями по принятой политике родительских моделей.
