# Обновление рабочего сервера через Git

Изменения кода сначала проходят проверки и публикуются в репозитории `the-gt99/slds_parser`. На рабочем сервере `/srv/slds-parser/app` применяется проверенный commit из `origin/main` через `git pull --ff-only`. Перед обновлением проверяются текущая ветка, commit и `git status`; чужие изменения не перезаписываются. Код, архивы сборки и патчи через SFTP не разворачиваются.

После обновления: `npm ci`, `npm run typecheck`, `npm test`, `npm run build`, `npm run db:migrate`; затем перезапуск нужных сервисов и проверки здоровья, jobs и ограниченный функциональный тест. Команды приложения выполняются от `slds-parser`.

Операционные манифесты и резервные копии данных отделены от обновления кода. Исправление размеров существующих карточек не означает разрешения публиковать новые товары. Перед изменением вариаций сохраняется их состояние и проверяется точное соответствие источнику.
