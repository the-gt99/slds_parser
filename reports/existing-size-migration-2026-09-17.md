# Исправление размеров существующих товаров, 17 сентября 2026

## Подтверждённый результат

- Исправлены 2 892 детские карточки, 9 667 вариаций: ошибочные US 10.5Y / 11Y / 12Y / 13Y заменены на точные K-термины. Основание — шкала GOAT, объявленные размеры и детская аудитория. ID вариаций, SKU, цены и остатки сохранены при миграции.
- После записи проверены все 9 667 размеров и исходные описания 2 892 карточек: расхождений нет.
- 17 существующих карточек Off-White переведены на исходные EU-размеры штатным экспортом. Полный предварительный diff не содержал изменений фотографий, категорий или описаний. Все 17 экспортов и последующие обновления остатков завершились успешно.
- В 15 карточках 82 полностью одинаковые лишние вариации переведены в draft. Ссылок на архивируемые вариации из заказов не было; записи и резервные копии сохранены.
- Исправлен отбор вариаций: draft не участвует в обновлении цен и остатков, включая sold-out. Совместимость со старыми снимками без статуса сохранена; publish/private продолжают обрабатываться.
- Добавлены точные профили размеров для 24 дополнительных Off-White и четырёх карточек с отсутствовавшей сеткой. Использованы объявленные размеры GOAT и существующие/точные термины WordPress, без округления и выбора ближайшего размера.

После миграции 1 569 детских товаров уже прошли автообновление; оставшиеся 1 323 возвращены в штатную очередь. Это снимок на момент окончания миграции, очередь продолжает работать.

Run 4: running, target включён, failed = 0. Последняя проверка здоровья: 240 630 товаров, 84 просроченных проверки. Поэтому inventory-health ещё degraded по давности, хотя сервисы работают. Сайт отвечает HTTP 200, API — status ok. Очередь WordPress не приостановлена.

## Что осталось

- В четырёх карточках дубли различаются ценой, количеством или способом учёта остатков. Автоматически не объединены: 1718571, 1719314, 1721666, 1723698.
- Из проверенных 62 карточек с исходными размерами 17 полностью обновлены, 45 ещё требуют работы с вариациями: у 25 остаются старые активные размеры, у 20 отсутствует безопасный набор существующих вариаций. Полный экспорт части этих карточек также меняет категории, материалы или изображения. Например, для Miu Miu предлагается заменить женскую категорию мужской, а для детских ботинок — категорию кроссовками. Такие изменения не применены.
- У Off-White Sliders Spray, source 253507, отсутствует классификация категории. Размеры уже подтверждены, но это не закрывает готовность полного экспорта.
- Общая группа «Нет безопасных существующих вариаций»: 7 213 на снимке проверки; у 1 986 есть явное сообщение об отсутствующем размере WordPress, у 5 214 нет уточняющих notices. Это не означает «цена не изменилась» и не доказывает отсутствие предложений GOAT.
- 19 противоречивых source-карточек из предыдущего аудита 601 товара не были исправлены догадкой. Готовность preview не равна публикации на сайте.

## Проверки и исправления побочных эффектов

Первый способ сохранения вызывал обработчик темы, удалявший из описания ссылку «другие расцветки» и пустые параграфы. 89 описаний восстановлены из резервных копий только при точном совпадении с этим преобразованием. Финальная проверка всех исходных описаний пройдена.

Операционный скрипт теперь меняет только точные атрибуты, родительские термины и индексы. Полный save родительского товара не вызывается. В запрос WooCommerce index добавлен parent ID, исключивший просмотр 2,5 млн строк для каждой вариации. Длинная транзакция через обработчики WordPress удалена; завершение и восстановление выполняются явно. Обнаруженная оставшаяся транзакция первого процесса была снята, затронутые карточки восстановлены и перепроверены.

Устранено различие URL одной фотографии между HTTP preview (CDN) и фоновым импортом (старый uploads URL). Snapshot использует общий CDN resolver. Для системного PHP CLI установлен совпадающий по версии пакет php8.3-sqlite3; другие пакеты не обновлялись. Проверка изменения реального содержимого товара сохранена.
