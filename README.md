# SLDS Parser

Базовый ESM-каркас на Node.js и TypeScript для конвейера сбора, обработки и экспорта данных о товарах.

## Реализовано

- универсальные DTO и контракты адаптера, процессора и экспортера;
- типизированные прикладные ошибки;
- Map-реестры компонентов;
- стабильная сериализация JSON и SHA-256-хэширование;
- unit-тесты на Vitest.

## Команды

- `npm run dev` — запуск точки входа через `tsx` в watch-режиме;
- `npm run typecheck` — проверка типов;
- `npm test` — однократный запуск тестов;
- `npm run test:watch` — тесты в watch-режиме;
- `npm run build` — сборка в `dist`.

Следующий этап — реализация инфраструктуры и конкретных интеграций поверх зафиксированных контрактов.
