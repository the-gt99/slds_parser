# Проверка размерных сеток

## Смешанная детская сетка GOAT US Youth

Exporter 1.27.0 применяет правило `wordpress-size-rules.ts` перед точным сопоставлением размера. Условия: source `goat`, сохранённый маршрут товара `metadata.route = sneakers`, размер `us-numeric/youth`. Значения 10.5, 11, 11.5, 12, 12.5, 13 и 13.5 выбирают K-термины через существующую группу mapping `infant`. Число размера, исходный DTO, SKU и ключ вариации не меняются. Размеры 1–7 остаются Y. Остальные числа, системы, аудитории и товары без подтверждённого маршрута правило не затрагивает.

Это правило разрешения размера на стороне target, не операция processing и не правило классификации. Обе группы детских размеров не требуют повторного processing. Используется единый путь для preview, полного экспорта, сохранённых и свежих offers. Для исправленной группы требуется mapping с явно заданными системой и аудиторией; возврата к ошибочному Y или mapping без аудитории нет. Отсутствующий K mapping блокирует экспорт либо явно исключается при `ignoreUnmappedSizeVariants=true`.

Обновление остатков не переименовывает размеры и не создаёт вариации. Если snapshot WordPress содержит активный старый Y-термин, заменяемый правилом, inventory patch блокируется до полной синхронизации товара. Уже снятые с продажи старые Y-вариации не блокируют обновление правильных K. Исправление существующей карточки требует реального preflight и проверки полного diff; установка кода сама по себе не исправляет старые карточки. Правило не меняет порядок терминов WordPress.
