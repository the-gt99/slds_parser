# Проверка размерных сеток

## Исправления 16 сентября

Exporter 1.25.0 ограничивает кеш размерных таблиц одной сборкой payload. Новая проверка и новая сборка для экспорта снова читают WordPress. Это устраняет сохранение уже исправленных конфликтов на всё время работы worker; варианты одного товара продолжают использовать одну полученную таблицу.

`scripts/apply-size-grid-repairs.php` принимает `deploy/size-grid-repairs-2026-09-16.json`. Preview является режимом по умолчанию, `--apply` проверяет точное исходное состояние и записывает резервную копию перед транзакцией. Добавлены 16 подтверждённых UK в женскую Prada и 21 UK в мужскую ASICS; неподтверждённые строки оставлены пустыми. Женская таблица Acne Studios перенесена из мужской обуви 25680 в женскую обувь 25859 по существующему разделу «Женщинам». Резервная копия production: `/tmp/size-grid-repairs-backup-20260916-102747.json`.

Источники дополнений: [Prada Women, Nordstrom](https://www.nordstrom.com/sizeguides/1481_sizeguide.pdf), [ASICS](https://www.asics.com/nz/en-nz/size-guide). Существующие числовые столбцы не менялись.

`scripts/add-range-size-terms.php` и `deploy/range-size-terms-2026-09-16.json` добавляют точные составные US-размеры взрослых Birkenstock. Это один размер целиком, например `7-7.5`, без округления и без размножения исходного предложения. [Официальный источник](https://www.birkenstock.com/us/product-info-overlay-sizeName.html). Созданы 21 термин pa_razmer, ID 26208–26228. `scripts/add-range-size-mappings.mjs` принимает JSON результата создания терминов, сохраняет прежние mappings в `/tmp/size-mappings-before-ranges-20260916.json`, обновляет target dictionary и добавляет точные mappings. Триггер PostgreSQL обновляет revision target. Оба скрипта требуют явного `--apply`; повторный запуск не добавляет дубликаты. Детские диапазоны этим изменением не затронуты.

`scripts/add-brand-size-grids.php` и `deploy/new-brand-size-grids-2026-09-16.json` добавляют мужские и женские сетки Loewe и The Row из указанных в manifest официальных источников. Запись разрешена только при полном отсутствии размерных метаданных бренда; вместе с таблицами сохраняется структура ACF для редактирования в админке. Аудит production: `/tmp/new-brand-size-grids-20260916-104346.json`.

Проверка Yeezy 25586 показала сохранённые категории 25680, 25859 и 25868; API находит таблицы. Скриншот с аксессуарами не соответствует сохранённому состоянию на момент проверки. Данные Yeezy в этой серии изменений не перезаписывались.

Исходный список 1269 товаров с размерными блокировками сохранён на parser в `/tmp/size-repair-cohort-20260916.json`; итоговая перепроверка выполняется заданиями `size-grid-final-20260916:*`. Это только preflight, без выгрузки товаров. Для Loewe/The Row после добавления таблиц дополнительно пересчитаны уже завершённые проверки через `new-brand-grid-20260916:*`.

Нельзя автоматически объединять конфликтующие варианты Off-White, заменять детские K-размеры на Y или брать одну модельную таблицу Veja для всех моделей. Старый общий справочник Lemaire и текущая карточка Anatomic Pump дают разные женские соответствия; общая таблица на их основе не добавлена.

## Частичные таблицы

При `ignoreUnmappedSizeVariants=true` отсутствие конкретной строки в успешно полученной размерной таблице обрабатывается так же, как отсутствие прямого size mapping: вариант исключается из payload и появляется в `ignoredSizeVariants` с исходным размером и причиной. Если подходящих вариантов не осталось, товар блокируется.

Отсутствие всей таблицы, конфликт преобразования, ошибка HTTP и неверный ответ остаются блокирующими. При выключенном флаге отсутствие отдельной строки также блокирует товар. Конвертер учитывает `conflicts` ответа WordPress; неоднозначный размер не считается просто отсутствующим.

## Дополнение Prada

Скрипт `scripts/add-prada-uk-size-column.php` запускается из корня WordPress. Без аргументов выводит проверяемый diff; `--apply` добавляет UK в мужскую таблицу бренда 4284, привязанную к категории 25680. Скрипт проверяет бренд, категорию, заголовки и совпадение существующих EU/US. Резервная копия перед изменением: `/tmp/prada-size-table-before-20260916.json` на WordPress-сервере. Повторное применение не меняет данные.

Источник соответствий: [Prada Men's Shoe Size Conversions Chart, Nordstrom](https://www.nordstrom.com/sizeguides/1475_sizeguide.pdf). Перенесены только 15 явно указанных строк UK 5–12, EU 39–46, US 6–13. Остальные строки UK оставлены пустыми. Существующие US/EU/CM/RU не изменяются.

Ошибка WordPress «нет однозначного преобразования» сама по себе не доказывает конфликт: API возвращает её и при отсутствии столбца исходной или целевой системы. У Prada отсутствовал UK; у проверенных мужских таблиц Dries Van Noten и Veja отсутствовал US.

## Повторная проверка

Снимок 4721 исходной размерной блокировки сохранён на parser-сервере в `/tmp/size-review-before-20260916.json`. Повторная проверка идёт только через `preflight_product`, ключи `size-review-20260916:*`. Она не запускает `export_product` и не изменяет карточки WordPress.

Старые результаты preflight нельзя считать текущим состоянием сопоставлений: четыре проверенных товара 226912, 226923, 226946, 226992 с прежней ошибкой категории успешно прошли повторную проверку на уже существовавших alias-настройках. Аналогично S/M/L и ONE SIZE уже имеют точные mappings в production; их старые блокировки требуют пересчёта, а не дублирования mappings.
